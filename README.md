# User Security Manager

A Power Platform Tool Box tool for managing user security roles and team memberships in Dataverse environments.

## Overview

Security Manager provides administrators with a comprehensive interface to:
- **Search and browse users** - Find users by domain name, full name, first name, or last name
- **View user details** - See user status (enabled/disabled), email, and business unit
- **Manage security roles** - View, add, and remove direct security role assignments
- **Manage team memberships** - View, add, and remove team assignments
- **Audit combined roles** - See all roles a user has, including those inherited from teams

## Features

### User Search
- Search across multiple fields (domain, full name, first/last name)
- Visual status indicators (enabled/disabled users)
- Business unit tags with color coding
- Sortable results by name and status

### Security Role Management
- Split-view interface showing assigned vs. available roles
- Bulk selection with checkboxes
- Add/Remove buttons with real-time enable/disable states
- Sorted alphabetically for easy navigation
- Collapsible sections for better organization

### Team Membership Management
- View all team assignments
- Add users to teams or remove them
- Split-view for assigned and available teams
- Bulk operations support

### Combined Role View
- See all roles (direct + team-inherited)
- Source attribution showing where each role comes from
- Clear visual distinction between direct and team roles
